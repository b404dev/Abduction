# Security policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting for this repository instead:

https://github.com/b404dev/Abduction/security/advisories/new

Include affected versions, reproduction steps, impact, and any suggested fix.
You should receive an acknowledgement within seven days. Please allow time for
a fix and coordinated disclosure before publishing details.
